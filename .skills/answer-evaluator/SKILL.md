# answer-evaluator

## 适用场景
用户完成一次模拟面试回答后，希望获得结构化评分、改进建议和追问方向。

## 触发关键词
评估回答、回答评分、评价回答、复盘回答

## 输入格式
包含会话 ID、题目和回答的任务，例如“评估回答：会话 5，题目：请介绍项目，回答：...”。

## 执行步骤
1. 从任务中读取会话 ID、题目和回答。
2. 调用 evaluate_my_interview_answer 工具。
3. 校验会话归属和题目是否属于该会话。
4. 返回评分、优势、改进方向和追问问题。

## 可调用工具
- evaluate_my_interview_answer

## 输出格式
返回总分、各维度评分、优势、待改进点、改进回答建议和追问问题。

## 质量检查
1. 只能评估当前登录用户可访问的面试会话。
2. 题目必须属于该面试会话。
3. 回答不足时明确指出信息不完整，而不是虚构亮点。

## 失败处理
会话不存在时返回 INTERVIEW_SESSION_NOT_FOUND；题目不属于会话时返回 QUESTION_NOT_IN_SESSION。
