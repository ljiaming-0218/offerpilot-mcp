# mock-interview

## 适用场景
用户希望针对指定岗位，结合自己的画像生成模拟面试题。

## 触发关键词
模拟面试、面试题、面试训练、面试准备

## 输入格式
包含岗位 ID 的自然语言任务，例如“针对 21 号岗位进行模拟面试”。

## 执行步骤
1. 从任务中读取岗位 ID。
2. 使用当前登录用户拥有的画像。
3. 调用 generate_my_mock_interview 工具生成并保存面试会话。
4. 返回题目、出题依据和面试会话 ID。

## 可调用工具
- generate_my_mock_interview

## 输出格式
返回岗位信息、3 道面试题、命中考点、出题依据和面试会话 ID。

## 质量检查
1. 只能使用当前登录用户可访问的画像。
2. 每道题必须基于岗位 JD、结构化要求或用户画像。
3. 不编造公司内部面试流程或面经出处。

## 失败处理
岗位不存在时返回 JOB_NOT_FOUND；用户没有画像时返回 USER_PROFILE_NOT_FOUND。
