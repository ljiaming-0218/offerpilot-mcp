# study-plan

## 适用场景
用户希望根据当前简历画像与真实岗位能力缺口生成学习优先级。

## 触发关键词
学习计划、学习安排、学习优先级、补齐技能、提升计划

## 输入格式
用户自然语言学习计划请求。画像由当前登录身份在服务端确定。

## 执行步骤
1. 读取当前登录用户拥有的最近更新画像。
2. 基于真实岗位匹配结果统计缺失技能出现频次。
3. 调用 generate_my_study_plan 工具生成学习优先级。
4. 返回重点技能、关联岗位示例和可执行行动建议。

## 可调用工具
- generate_my_study_plan

## 输出格式
返回重点技能、目标岗位数量、关联岗位示例和行动建议。

## 质量检查
1. 只能使用当前登录用户可访问的画像。
2. 优先级必须由真实岗位缺失技能统计得到。
3. 不编造课程、认证、学习时长或就业结果。

## 失败处理
没有画像时返回 USER_PROFILE_NOT_FOUND；没有可用岗位数据时说明需先采集岗位并抽取技能。
