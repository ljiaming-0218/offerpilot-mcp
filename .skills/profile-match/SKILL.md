# profile-match

## 适用场景
用户希望根据自己的简历画像，查看匹配岗位、已具备能力和待补齐能力。

## 触发关键词
我的匹配、岗位匹配、匹配岗位、适合我的岗位、匹配度、简历匹配

## 输入格式
用户自然语言匹配请求。画像由当前登录身份在服务端确定。

## 执行步骤
1. 读取当前登录用户拥有的最近更新画像。
2. 调用 match_my_profile 工具计算岗位匹配。
3. 返回推荐岗位、匹配技能和能力缺口。

## 可调用工具
- match_my_profile

## 输出格式
返回岗位总数、推荐岗位、匹配分数、已命中技能和待补齐技能。

## 质量检查
1. 只能使用当前登录用户可访问的画像。
2. 不编造岗位或匹配分数。
3. 无可用岗位时明确说明原因。

## 失败处理
未创建画像时返回 USER_PROFILE_NOT_FOUND，并提示先上传简历或创建画像。
