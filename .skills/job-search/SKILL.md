# job-search

## 适用场景
用户想查询、筛选、统计岗位数据。

## 触发关键词
查询、哪些岗位、筛选、统计、热门技能、成都、RAG、Agent、Text2SQL

## 输入格式
用户自然语言问题。

## 执行步骤
1. 理解用户查询意图。
2. 调用 text2sql_query 工具。
3. 检查 SQL Guard 结果。
4. 返回 SQL、查询结果和简要说明。

## 可调用工具
- text2sql_query
- search_jobs
- list_skills

## 输出格式
返回岗位列表、统计结果、生成 SQL 和 SQL 安全检查结果。

## 质量检查
1. 不能编造数据库中不存在的岗位。
2. 查询必须经过 SQL Guard。
3. 如果结果为空，说明没有匹配数据。

## 失败处理
如果 SQL 不安全或查询失败，返回失败原因。
